# ระบบตรวจสอบผลคะแนนและเงินรางวัลมาตรฐานจัดส่ง (Sprinkle Delivery Rewards)

เว็บแอพพลิเคชันสำหรับตรวจสอบผลการประเมิน เงินรางวัลมาตรฐาน และวิเคราะห์หัวข้อที่ตกเกณฑ์/ถูกหักคะแนนรายเบอร์รถ

---

## 🌟 ฟังก์ชันใหม่ล่าสุด

### 1. 🔐 ระบบล็อกอินด้วยรหัสพนักงาน หรือเบอร์รถ
- **สำหรับพนักงานขับรถ / ผู้ประกอบการ**:
  - กรอกรหัสพนักงาน (เช่น `90872`, `90651`, `272568`) หรือเบอร์รถ (เช่น `13101`, `13104`, `13L11`)
  - ระบบจะล็อกอินและพาเข้าหน้าผลงานและเงินรางวัลของตนเองทันที
- **สำหรับหัวหน้างาน / ธุรการ**:
  - กรอกรหัสหัวหน้างาน (เช่น `171873`, `171938`, `171923`) หรือกดปุ่ม "เข้าสู่ระบบในฐานะหัวหน้างาน" เพื่อตรวจดูได้ทุกเบอร์รถในสาขา และอัปโหลดไฟล์เดือนใหม่

### 2. 📱 UI ปรับเปลี่ยนอัตโนมัติระหว่าง "โทรศัพท์มือถือ" และ "คอมพิวเตอร์"
- **บนโทรศัพท์มือถือ (Mobile Phone)**:
  - ดีไซน์สไตล์ Native Mobile App คมชัด อ่านง่าย สบายตา
  - แถบเมนูด้านล่าง (Bottom Navigation Bar):
    - 💰 **สรุปรางวัล**: ยอดเงินรางวัลตัวใหญ่เด่นชัด สถิติยอดส่งถัง และเงินรางวัลรายกลุ่ม
    - ⚠️ **จุดที่ตก**: รวมเฉพาะรายการที่ตกเกณฑ์/ถูกหักคะแนน พร้อมยอดเงินที่โดนหัก
    - 📋 **เกณฑ์ทุกข้อ**: แสดงเกณฑ์ประเมินครบ 1.1 ถึง 4.7 ในรูปแบบ Accordion แตะเปิด-ปิดง่าย ไม่ต้องเลื่อนตารางแนวนอน
- **บนคอมพิวเตอร์ (Desktop)**:
  - แสดงผลเต็มหน้าจอ แบ่ง 2 ฝั่ง (เลือกเบอร์รถด้านซ้าย + รายละเอียดพร้อมตารางครบทุกข้อด้านขวา)
  - รองรับการพิมพ์สลิปสรุปผลงาน (Print Slip / PDF)

### 3. 📅 ระบบดูผลงานรายเดือน & นำเข้าเดือนใหม่
- ดูย้อนหลังได้ครบ 9 เดือน (มกราคม ถึง กันยายน 2569)
- มีปุ่ม **"+ นำเข้าเดือนใหม่"** สำหรับลากไฟล์ Excel/CSV ของเดือนถัดไปเข้ามาอัปเดตเองได้ทันที
