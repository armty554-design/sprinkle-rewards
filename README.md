# ระบบตรวจสอบผลคะแนนและเงินรางวัลมาตรฐานจัดส่ง (Sprinkle Delivery Rewards)

เว็บแอพพลิเคชันสำหรับตรวจสอบผลการประเมิน เงินรางวัลมาตรฐาน และวิเคราะห์หัวข้อที่ตกเกณฑ์/ถูกหักคะแนนรายเบอร์รถ ครบทั้ง 18 สาขา

- **เว็บไซต์ใช้งานจริง:** https://sprinkle-rewards.vercel.app/
- **คู่มือการใช้งานพร้อมภาพประกอบ:** [docs/USER_MANUAL.md](./docs/USER_MANUAL.md)

---

## 🌟 ฟีเจอร์หลัก

1. **ระบบเข้าสู่ระบบด้วยรหัสพนักงาน & การแยกสิทธิ์ (RBAC):**
   - **พนักงานขับรถ / ผู้ประกอบการ (ผปก.):** เข้าสู่ระบบด้วย **รหัสพนักงาน** เพื่อตรวจสอบเฉพาะรถของตนเอง (ไม่เห็นข้อมูลรถคันอื่นและเมนูผู้บริหาร)
   - **หัวหน้างาน / เจ้าหน้าที่ออฟฟิศ / แอดมิน:** ดูภาพรวมครบทุกสาขา (`ตรวจรายคัน`, `ภาพรวมทุกคัน`, `สถิติสาขา`, `เปรียบเทียบผู้บริหาร`, `มาตรฐานยอดเยี่ยม 2569`, `คะแนนกลุ่มงาน 69 Looker`) และจัดการระบบใต้เมนู **ตั้งค่า**

2. **UI ปรับอัตโนมัติทั้ง Desktop และ Mobile:**
   - **Mobile:** เมนูด้านล่าง 3 แท็บ (`สรุปรางวัล`, `จุดที่ตก`, `เกณฑ์ทุกข้อ`) พร้อมปุ่มพิมพ์สลิป PDF
   - **Desktop:** มุมมองเต็มหน้าจอพร้อมการ์ด KPI, ตัวกรองหลายมิติ, รายงานผู้บริหาร, และการวิเคราะห์รายสาขา

3. **ซิงค์ข้อมูลรายเดือนจาก Google Sheets อัตโนมัติ:**
   - รองรับข้อมูล `01-2569` – `09-2569` และตรวจจับเดือนใหม่ (`10-2569` – `12-2569`) อัตโนมัติ

4. **ระบบ Deep-Linking & ปุ่มคัดลอกลิงค์:**
   - แชร์ลิงค์เฉพาะแท็บ เดือน สาขา หรือเบอร์รถ พร้อมจำหน้าเป้าหมายข้ามหน้า Login และบังคับตรวจสอบสิทธิ์ RBAC อัตโนมัติ
